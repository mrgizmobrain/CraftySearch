# Changelog

## 1.0.0

First release, for Minecraft 26.2 (Fabric).

- A storage panel beside the inventory and the crafting table lists every item in nearby containers with its total, with search (`#tag`, `@mod`, enchantments and levels) and sorting. A key (G) opens it as a full screen.
- Show where an item is: containers holding it are outlined through walls with their counts, and its slots are marked when one is opened. Markers on screen for shader packs.
- Craft from storage through the vanilla recipe book, including crafting the missing ingredients first.
- Take and put away from the panel: clicks, shift-clicks, the scroll wheel, shift-drags, throwing with the drop key, and opening an item's container. Items are put away the way a copper golem sorts them.
- Chests, barrels, shulker boxes (their contents too), hoppers, droppers, dispensers, chest and hopper minecarts, and chest boats.
- Works on any server with only the client installed (client-only mode); with the mod on the server too, or in singleplayer, it's instant and reaches every container in range (server mode).
- Server mode follows claims (Open Parties and Claims, Flan, Common Protection API), spawn protection and container locks.
- Client-only mode: remembers what you've opened, marks containers someone else has used, can check every container within reach at once (Shift-click the sort button), and has an "Anti-cheat safe" switch and an "All interactions" switch for servers that need care.
- "Leave one" keeps one of each item in every container, so sorting keeps working.
- Works with Mod Menu, JEI, REI, Mouse Tweaks and Inventory Profiles Next.
